# Task 2 – Semantic HTML5 & Accessible Component Architecture

## Project Overview
An accessible multi-page enterprise dashboard built using semantic HTML5 and accessibility best practices.

## Project Structure

- `index.html` – Main dashboard
- `pages/reports.html` – Reports page
- `pages/settings.html` – Settings page
- `components/data-table.html` – Accessible employee data table
- `components/accessible-form.html` – Employee registration form with validation
- `components/modal.html` – Accessible confirmation dialog

## Technologies Used
- HTML5
- Semantic HTML
- ARIA attributes
- Native HTML form validation
- JavaScript

## Accessibility Features
- Semantic HTML5 elements
- Descriptive navigation labels
- Keyboard navigation
- Skip-to-main-content link
- Accessible table headings
- Proper form labels and fieldsets
- Native dialog with keyboard support

## Validation and Testing
- All 6 HTML files checked using the W3C HTML Validator.
- Zero HTML validation errors after corrections.
- Keyboard navigation tested.
- Form validation tested.
- Modal keyboard interaction tested.
