Server – Backend Application

Overview

The server folder is reserved for the backend resources of the project.

It will handle application logic, data processing and communication between the frontend and external or internal APIs.

- Provide REST API endpoints.
- Handle application data.
- Process frontend requests.
- Manage issue-related information.
- Support communication between the client and server.

- JavaScript
- Node.js
- REST API
