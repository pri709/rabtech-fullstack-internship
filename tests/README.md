Testing Documentation

Overview

The tests folder is reserved for testing resources and documentation related to the project.

Testing will help verify that the application works correctly and follows accessibility and responsive design requirements.

Planned Testing Areas

1. Accessibility Testing

- Keyboard navigation.
- Accessible names and labels.
- Alternative text for images.
- Colour contrast.
- Semantic HTML structure.

2. Responsive Design Testing

- Mobile screen layouts.
- Tablet screen layouts.
- Desktop screen layouts.
- Horizontal overflow checks.

3. Functional Testing

- Navigation links.
- Search and filtering.
- Form validation.
- Interactive components.
- API responses and error handling.

Planned Tools

- Google Chrome Lighthouse.
- Browser Developer Tools.
- W3C HTML Validator.
- Manual keyboard testing.

Development Status

Testing documentation has been initialized. Detailed test cases and test results will be added as the application is developed.
