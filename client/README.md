Client – Frontend Application

Overview

The client folder contains the frontend resources of the project.

It will be responsible for displaying the user interface and allowing users to interact with the application.

Technologies

- HTML5 – Semantic page structure.
- CSS3 – Styling and responsive layouts.
- JavaScript – Interactive functionality and DOM manipulation.

Planned Features

- Accessible navigation.
- Responsive dashboard layout.
- Accessibility issue listing.
- Search and filtering.
- Issue details and status updates.
